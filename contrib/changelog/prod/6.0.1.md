* We’ve refreshed some of the behind-the-scenes building blocks to keep the app’s connection to our services as secure as ever. No action needed on your end - just update and carry on.
* Obfuscated servers now run on NordWhisper instead of OpenVPN XOR. Obfuscation kicks in automatically when you select NordWhisper, so the “set obfuscate” command is no longer needed — and it’s gone.
* The “nordvpn set protocol” command now selects both the technology and protocol. For example, to select OpenVPN UDP, just use “set protocol openvpn_udp,” and that’s it.
* You’ll no longer find the P2P server group as an option in the CLI, app, or tray. P2P, however, isn’t going anywhere. In fact, all our regular servers now support P2P. Just pick a location, and you’re good to go.
* We won’t mark virtual servers as such anymore. Sometimes a server is just a server.
* As part of routine CLI housekeeping, we removed the outdated “threatprotectionlite,” “tplite,” “tpl,” and “cybersec” aliases. Use “nordvpn set protection on” to turn on real-time protection.
* We also removed the old “whitelist” alias for the “allowlist” command.
* We’ve continued improving the GUI app for those navigating with a screen reader.
* OpenVPN has been upgraded to a satisfyingly higher version number: 2.7.7. DCO now works out of the box on systems running Linux kernel 6.16 or newer, giving you faster OpenVPN connections.
* Before an update starts, the app now closes any open GUI window. This way, the old GUI won’t hang around after the new version is installed.
* You can no longer set auto-connect to a specific server number. If that was part of your setup, you still have plenty of options: choose a country, city, or server group, or let the app pick the fastest server for you.
* Fixed: Port forwarding on dedicated servers now works with Meshnet and LAN discovery turned on.
* Fixed: The “nordvpn set defaults” command wasn't setting quite all the defaults. That's fixed now.
* Fixed: The tray “Pause” menu on Linux Mint was serving a whole lot of nothing. It now shows the options to pause or disconnect your VPN connection. And once you do pause, the timer keeps moving too.
* The tray and CLI now also show your specialty server group, just like the GUI app.
* LAN discovery now supports multicast and SSDP.
* And lastly, a bunch of background improvements made it into this release too, including optimized API request transport and better login token handling.
