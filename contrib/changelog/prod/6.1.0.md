* Fixed: Connecting to the VPN would break LAN DNS resolution on systems using systemd-resolved, and the problem persisted after disconnecting. We’ve taken care of it.
* Fixed: Turning off Meshnet would also disconnect you from a dedicated IP server. Now it only does what it says.
* Fixed: Auto-connect would stop working if you switched to a protocol that didn’t support the server type set for auto-connect. Now the app prevents such incompatible combinations.
* Fixed: The GUI app would sometimes crash at startup. Not the experience anyone was hoping for.
* Fixed: You can now use UK, GB, uk, or gb to connect to the United Kingdom. All four work consistently.
* Fixed: The tray icon would sometimes introduce the app as “systray_2902” or similar. A bold attempt at rebranding, but one we hadn’t approved. Now it sticks to NordVPN.
* The app has become a little bit more helpful for those of you using screen readers. We’ve improved announcements for tabs, custom DNS, allowlist, and the app version.
* The diagnostics command now works in the snap app version, too.
* Logs no longer contain dedicated IP hostnames or IP addresses.
* And finally, we’ve made several security and stability improvements. The kind you only notice when they’re missing.
