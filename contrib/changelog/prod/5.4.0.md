* For less frustration when too many connection attempts trigger a temporary limit, NordLynx now detects the issue faster and gives you clearer guidance on what to do next.
* OpenVPN got a speed boost. We’ve added support for Data Channel Offload (DCO) to improve connection throughput. If DCO has piqued your interest, check the README in our GitHub (github.com/NordSecurity/nordvpn-linux) repository for setup instructions.
* Threat Protection Lite is keeping up with the times — the real time, to be exact. It’s now called “Real-time protection,” and the new name comes with a new command to turn it on: nordvpn set protection on.
* We’ve continued making NordVPN more accessible. You can now hear better screen reader announcements, navigate with your keyboard, and move through menus with ease. 
* We fixed an issue where the app could incorrectly show “Disconnected” even when the operating system tunnel was still very much active.
* If auto-connect has been reconnecting you somewhere other than your selected country, it should no longer be doing that.
* As part of our campaign against connection weirdness, we also fixed a few platform-specific connection issues.
* We’ve removed outdated info about a deprecated flag from the CLI help. Some goodbyes just take a little longer.
* And finally, a whole lot of internal improvements made it into this release too, including HTTP transport handling, OpenVPN configuration versioning, and CDN support for older distributions.
